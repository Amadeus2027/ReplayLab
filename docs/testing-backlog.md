# 测试待办

所有版本仅执行当前改动必要的验证。以下项目仅记录，**由用户主动提出后开展**，没有自动执行版本或日期。

| 项目 | 当前延期原因 | 启动条件 |
| --- | --- | --- |
| 多站点、多浏览器、跨平台兼容矩阵 | 核心流程尚在收敛，成本较高 | 用户提出 |
| Liquid Glass 的 Safari/iOS 实机、Firefox 与低性能设备兼容 | 当前仅验证 Chromium 桌面及窄屏布局；折射受浏览器支持限制 | 用户提出 |
| 大样本真实视频步骤准确率/召回率/任务成功率 | 需要标注样本与付费模型预算 | 用户提出 |
| 长视频与高并发压力测试 | 本轮定位为单用户短视频 | 用户提出 |
| 大规模模型对比与性能基准 | 当前仅完成 DeepSeek 的单个可控场景验证 | 用户提出 |
| 广泛的恶意页面、提示注入与安全审计 | 首轮只验证必要执行约束 | 用户提出 |
| Agent Skill 跨客户端安装兼容矩阵 | 初期优先统一 CLI 入口 | 用户提出 |

必要验证的实际结果见 `docs/validation.md`。每次修改按影响范围选择检查，不默认反复运行整个测试集或模型。
