# 视频流程与 Agent 代操作

用户提供视频，理解其中的操作流程，再授权 Agent 为自己完成任务。工作台围绕这三个动作组织。

采用黑色和中性灰为主、少量淡紫选中态的视觉语言。参考 [n8n](https://n8n.io/) 的节点画布和 [Gumloop](https://www.gumloop.com/) 的 Agent 工作流交互，继续复用 React Flow 与 Lucide；没有复制其品牌、图片或业务代码。

v0.1.1 将工作台、弹窗和 `examples/demo` 示例页统一为深色玻璃材质。配色、模糊、圆角与边框共用 [theme.css](../examples/demo/theme.css)，Agent 操作栏直接接入 MIT 许可的 [liquid-glass-react](https://github.com/rdev/liquid-glass-react)。SVG 折射只在背景层，文字和按钮独立呈现；没有为此引入整套 CSS 框架。其他面板采用 CSS 半透明与细高光，避免每个节点都运行折射效果。不支持背景模糊时使用实色回退；Safari/Firefox 的折射表现受上游实现限制，尚未实机验证 iOS。

工作台主界面与执行确认的截图见 README；[深色示例页](assets/replaylab-demo.png)与[手机宽度示例](assets/replaylab-demo-mobile.png)展示相同设计语言。历史录屏及帧证据保留原色；视频里出现浅色页面不代表当前产品主题退回浅色。

- 左侧：按可读标题查找流程，新建视频任务；连接设置放在侧栏底部。
- 中央：按视频顺序展示操作节点，支持画布/步骤列表切换；手机首次打开默认列表，便于阅读完整步骤。不承担通用编程编辑器角色。
- 右侧：当前步骤对应的画面和时间、Agent 将做什么、完成后检查什么。原视频可用时可播放并定位到步骤。
- 主操作：让 Agent 执行。一个确认窗口收集参数、展示运行条件和敏感动作，用户明确授权后依次保存、审核并执行。
- 运行反馈：根据真实执行报告显示步骤状态、验证结果和页面截图。没有模拟进度或伪造模型恢复结果；修改流程后隐藏旧的完成状态。
- 复用：执行通过后下载 Skill ZIP。失败则停止，展示原因；重新执行从第一步开始。

初版仍依赖本地服务和用户配置的视觉模型。首次连接令牌在设置中输入一次；这属于当前开发版本的连接方式。界面中的手工示例会明确标注，不能作为真实视频识别能力的证据。

完整协议、复杂断言及高级流程结构可通过 CLI 与工作流文件修改；消费者主路径使用表单和步骤详情。
