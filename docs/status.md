# v0.1 实施状态

此版本是首轮可运行实现，尚未完成真实视频识别能力验收。

| 环节 | 当前实现 | 边界 |
| --- | --- | --- |
| 视频输入 | 本地文件、工作台上传、yt-dlp 公开链接适配 | 上传最大 200 MB；不导入 Cookie，不处理 DRM；站点兼容未全面验证 |
| 视频处理 | FFmpeg 稀疏抽帧、scene 检测与变化前后取帧 | 最多 32 帧；细微点击可能漏检，无自适应二次模型精扫 |
| 视觉编译 | OpenAI SDK、JSON Schema 提示、Pydantic 校验 | 尚未配置实际模型，无真实识别成功率数据 |
| 证据关联 | 校验帧 ID、视频时间范围与步骤引用 | 人工编辑/import 的证据引用由用户核对 |
| 运行时绑定 | Playwright role/name、label、text、placeholder | 严格唯一定位；尚无视觉回退后端 |
| 执行与验证 | 固定动作、逐步断言、任务最终断言、首错停止、报告/截图 | 仅单标签页、新会话；无断点恢复和登录态导入 |
| 工作台 | 黑色 React Flow 画布/列表、帧证据和原视频、表单编辑、Agent 执行确认、真实步骤进度、Skill ZIP 下载 | 结构与复杂断言用 CLI/JSON 调整；不是通用拖拽编排器 |
| Skill | 当前工作流通过验证后导出，修改后不能沿用旧报告 | 依赖 ReplayLab 本地运行时；未在各 Agent 中安装验证 |

## 最小协议与执行边界

视频恢复输出可见语义目标。运行时用 Playwright 将其绑定到当前 DOM，不将视频坐标直接用于新页面。

动作只包括 `click`、`fill`、`select`（按可见标签）、`check`、受限 `press` 和 `navigate`。断言包括 `visible`、`text`（精确文本）、`url`（精确地址）、`value` 和 `checked`。未知输入使用 `${parameter}`，运行前要求提供值。

编译器设置用户给定的起始 URL 和允许 origin，忽略模型对执行环境的授权。所有模型步骤强制待审核。用户核对前置条件与敏感步骤后明确批准，执行器再检查待确认项、审核状态、参数和敏感操作确认。模型的敏感性分类只是提示，用户审核仍需检查其准确性。

执行使用新的浏览器上下文，限制导航来源，关闭新弹窗并禁用 service worker；不执行任意脚本或 shell。它不是恶意网站的完整安全沙箱，也不声称具备可靠的自动敏感操作识别能力。

导出报告以 SHA-256 绑定当前完整工作流；编辑后必须再次执行通过。CLI 和工作台共用协议、执行器和导出器。当前本地服务采用单进程内任务锁，不支持多 worker 或多个 CLI 同时修改同一任务。

## 暂未纳入本轮

WXT 浏览器扩展、Native Messaging、tabCapture、语音转录、Midscene 视觉后端、UI-TARS 桌面操作、多模型并行片段推理。这些模块按需求引入成熟依赖，不先搭空壳。

浏览器扩展与复杂采集属于后续范围；语音与自适应精扫是否加入 v0.1，依据首个真实视频实验中发现的缺口决定。

## 下一步核心验收

配置可用视觉模型，选择一段 30–90 秒网页操作视频，记录原始模型流程、人工修正量、新会话完整任务结果、分阶段耗时与成本。该能力通过之前，不宣称 v0.1 已完成。
