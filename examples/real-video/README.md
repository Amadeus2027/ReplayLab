# v0.1.1 真实录屏样本

`source.webm` 是 Playwright 在真实浏览器中录制的 41.08 秒视频，1280×1200 原生分辨率。网页源代码在 `../demo/`。项目名随机生成，避免把固定示例答案当作恢复结果。

这段视频录制时示例页为浅色；当前示例页已统一深色玻璃样式，原视频保留原色。相同模型工作流在改版后也已回放通过，见实验报告。`sample.json` 中的 `model_called:false` 指录制阶段没有模型调用，实际推理收据单独保存在报告目录中。

- `sample.json`：视频摘要、长度、复现网址与本地服务端口。
- `reference.json`：独立参考动作，用于推理完成后的对照，不传给模型。
- `expected.json`：独立任务结果断言，不由模型生成。

这是自动录制的受控网页演示，包含填写名称、选择优先级、开启提醒、创建项目和搜索。它不代表真实第三方网站兼容性，也不包含原始鼠标/键盘事件元数据作为模型输入。

复现只需把 `source.webm` 交给 `replaylab analyze`。不要导入参考动作替代分析。完整命令与实际调用记录见 [实验报告](../../docs/validation/v0.1.1/README.md)。
